## Working agreements proposed by the plan

- Keep `main` demo-ready; make focused feature branches and open reviewed pull requests.
- Review each change against its phase acceptance criteria and the current demo path.
- Hold a 15-minute daily stand-up and a weekly scope/risk review while the team is active.
- Track work as Backlog, Ready, In progress, Review, and Done. Each item should carry a phase ID and an owner.
- Record decisions with date and owner in `DECISIONS.md` so unresolved assumptions stay visible.
- Complete a clean local start and run the existing suite before accepting a change.
