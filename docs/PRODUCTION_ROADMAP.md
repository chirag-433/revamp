# Post-finale production roadmap

Durations are planning estimates from the supplied phase plan. Start dates and exit measures must be agreed with AICTE data owners and the project mentor.

| Stage | Indicative duration | Work | Exit evidence |
|---|---:|---|---|
| Discovery | 2–3 weeks | Confirm source systems, owners, access paths, institution master, statuses and service timelines. | Signed data-sharing approval and field mapping. |
| Pilot | 6–8 weeks | Connect approved RB and PGRC sources in read-only review mode; resolve institution data quality. | Officer-reviewed overlap precision meets an agreed threshold. |
| Expand | 6–8 weeks | Add approved Bureaus/Cells and regional roles; deploy SLA alerts and adopted reports. | Active use across participating groups and measured SLA coverage. |
| Harden | 4–6 weeks | SSO, security audit, load testing, accessibility, backup and recovery exercises. | Security and recovery reviews pass; uptime target is approved. |
| Scale and learn | Ongoing | Consider write-back, multilingual case text, predictive models and mobile alerts only with approved data and use cases. | Reduced duplicate actions or faster case disposal measured against a baseline. |

## Dependencies and decision gates

- No production connection until the data owner approves the interface, purpose, and access controls.
- No complainant data until privacy review, minimization, retention, and audited access are agreed.
- No write-back until case ownership, conflict resolution, rollback, and operational accountability are tested.
- Agree accuracy, uptime, scale, and response-time targets using observed pilot data rather than the planning values in the source plan.
